# 选定方法组后的阅读与图示

## 固定范围并诚实阅读

列清本组论文、首版日期、所读修订版与来源，下载可取得的全文，记录 PDF SHA256。读正文、实验、参考文献和全部附录/补充材料。另记关键图表是否渲染检视、源码是否读过、代码是否运行。

全文未取得标 `abstract_only`；只读部分标 `partial`；完整正文/附录已读才标 `full_paper`，并明确 reading_scope。哈希和文件存在不证明已读。访问验证或材料缺失不得以猜测补齐。

全文若推翻摘要分类，修正主路径或实现/训练标签并重算相关统计；保留依据，不声称局部修正等于全库复核。

## 三轴与贡献组合

| 轴 | 记录内容 | 边界 |
|---|---|---|
| 问题 | 相对先例是否改变场景、对象、目标或代价视角 | 交代问题定义与适用范围；不把新数据集直接等同新问题 |
| 认知 | 现象、反例、解释及成立条件 | 观察、作者解释、阅读者推导分开；因果主张需要区分替代解释的证据 |
| 方法 | 信号、机制、粒度、阶段，以及迁移/组合/补偿 | 允许多标签或无变化，不强迫每篇都有全新信号和认知 |

“贡献组合”是一句相对先例的概括，如旧问题×新信号、旧问题×新机制、新问题视角×已有机制、迁移/组合/补偿。它不是第四轴，也不是用于互斥计数的类别。

交代哪篇已知工作提出或明确了问题，哪些工作更换了解法。最早收录、本组最早、未找到先例都不证明全领域首创；修订版新增引用不能回填到首版。

## 逻辑与证据

梳理：原有做法 → 不足 → 可用观察/认识 → 方法模块 → 验证方式 → 成立边界。对主要主张记录“证据位置、支持到哪里、尚未证明什么”，引用章节/式/图表/页码。

比较模型、数据、质量指标、预算、作用阶段、实现和硬件。同一配置的结果放在一起，不拼接不同配置的峰值。FLOPs不换算成同倍速度，CUDA profiler时间不自动等于并发服务端到端延迟；比较条件不同的结论先解释条件再作判断。

信号与机制贡献可借组件替换/消融判断；A+B比原模型好不单独证明协同。理论强假设、原文数字或层边界冲突保留，不自行修正文献。

## 实现与训练标签

- 软件侧：算法、kernel、编译或调度，硬件结构不变。
- 含硬件设计：贡献包含电路、数据通路、计算单元、存储/互连修改；两者兼有归此类。FPGA/ASIC/GPU名称不能单独分类。
- 无新增训练：加速方案不要求新增参数训练。统计校准、阈值选择不自动算训练。
- 仅辅助组件：目标及有效参数冻结，仅独立草稿、预测器/控制器等训练。
- 目标模型：更新主干、原router、专家、LoRA或最终生成的压缩/蒸馏学生。

按主方案依次判：目标更新 → 辅助训练 → 无新增训练。缺失保持 null，不默认免训练。“轻量”是成本描述，不是互斥类别；既往预训练与方案新增/必需的专门训练区分。

这些属性在适用的领域启用；非模型领域可留空并在界面隐藏无意义的维度，不能为凑标签假造训练对象。

## 团队和一跳脉络

团队取论文署名当时的机构，不据姓名/现职推断实验室。核查参考文献和实验表中的实际 baseline，做有界后向检索寻找明确将其作为对照的后续工作。

箭头从比较/组合/引用方指向被比较方。区分 baseline、combination、citation；无论文身份的内部消融单独说明。仅引用不等于沿用、实验比较或超越。外部参考标清是否全文已读、是否纳入主统计。

未检索到边不等于没有关系；交代已查范围和缺口。默认不加入相邻解法和迁移机会清单，不扩展为穷尽引用网络。

## 图先解释，文字补边界

1. 问题图解释问题变化；方法图解释具体处理规则。共同任务/输入和原始处理只画一次，不同方法同时并排呈现，使用相同对象、颜色、阶段顺序及记号。
2. 图中显示信号、选择、保留/删除/替代、路由、权重与执行范围。不同对象数、调用次数、token数、物理池区分标注。
3. 同一数值例只在输入和机制真能对齐时使用；额外相似度、预测信号、校准参数明示。训练前提或模块不同的方法用共同任务作定性对比，不强套同一checkpoint。
4. 构造示例写清非论文实测/复现，预算不同不比较性能。未知权重、选集、奖励留空，不为了图完整而猜。
5. 论文截图写图号/版本；重绘写清规则来源、简化与教学构造。图下简短条件，成本、推导、局限和来源可折叠。
6. 图已说明的机制不再配重复大表，逐篇阅读也不堆同图。不用下拉框逐个切换方法；需要数值核算/排序时再附表。
7. 继承现有模板的颜色、排版、导航。检查浅深主题和窄屏，分别说明静态/浏览器/结构检查，不能夸大。

`flow`图组件用三个显示阶段概括机制，完整逻辑可任意长度；这只是绘图布局，不要求研究分类或论文方法恰好三步。四专家路由组件只适用于其定义确实对应的教学例；其他领域用通用flow图或增加有来源的图组件。
