# 阶段与人的决策点

## 1. 范围和来源

记录研究对象、任务与目标、准入/排除边界、允许的实现范围。由 AI 推荐会议/期刊，而非要求陌生领域的用户自行列清来源。依据包含官方 scope、近期代表作、认可度及覆盖互补；关键词只用于发现线索。

由人确认目标来源、年份与轨道。源名单的认可度和语义相关性分开；目标顶会也可能需要系统/硬件等邻近来源补足覆盖。资源、训练与复现条件通常在选定分支后判断；用户明确规定的硬约束直接记录执行。

状态写入 `state.json`。这是决策记录，不是每次执行前重复询问的批准表。用户已给定的选择直接沿用。

## 2. 检索与收录

开始建库前按 [completion.md](completion.md) 声明检索单元并记录队列。默认按人确认的完整范围处理；小样本仅用于提出分类维度或明确同意的试跑。完成约定范围处理后再称“建库完成”；有限查询的完成不等于领域穷尽。

- 扫描确认来源的正式目录，核对年份、轨道、分页和能取得的摘要；搜索命中数不等于相关论文数。
- 以主题/机制的不同表述补检前沿预印本；记录查询、时间范围和分页。再用少量综述、代表论文及作者清单反查缺口。
- 关键词批量召回后，逐篇按标题与完整可用摘要判断相关性与分类；不能只截取摘要前段后标为完整阅读。明显范围外的题名可记录 title_only 排除；歧义则补摘要/方法介绍或记信息不足，不能靠“没说某架构”补齐准入证据。
- 区分来源全集、已扫描题录、筛选保留集、优先阅读队列。有限查询完整分页也不等于整个领域检索完备。
- 以 arXiv/DOI/OpenReview 等强标识和完整题名去重，优先目标来源的正式版本；缩写、相似标题不能单独决定合并。保留别名、首版信息及冲突。
- 主统计采用目标来源和预印本两类。Findings/Workshop/其他轨道是否纳入依确认配置；若排除，不能改包装成预印本补入。
- 收录方式不对称、版本升级及来源扩充都会影响趋势，留简短边界说明，不将收录状态解释为发表成功率。

`search-log.json` 每项可记录 source_id、URL/query、年份、轨道、预期/已读页数、缺口及处理结果。未取得摘要、遭验证页或限流时保留缺口；使用独立可访问的一手来源，尊重访问限制。

按已确认边界完成召回记录的去重与处置，不能先挑数百条就转到分支选择并将余项消失。新增查询或来源结果继续进入队列。需要先看阶段性结果时照常保留导航，但标题和交付说明要标明未完成；等待人的分类确认也不等于停止已授权的来源抓取与初筛准备。

## 3. 定场景

AI 小规模预调研：少量综述提供已有维度，不同年份/来源/方法的代表摘要检验维度。提出一个首选方案及必要的替代，列清判据、边界、典型工作与为何影响瓶颈、评价或实验方式。

优先按任务与工作负载区分：输入、输出、运行条件中真正改变问题的维度才进第一层。范围内不变的条件写作准入约束。架构、通用适用性和实际评估对象分别记录，不把跨架构方法强分成一种架构。

人确认划分并选择优先场景。全库按规则分配唯一主场景；其他适用范围保留标签。数量悬殊是检查信号，不要求均衡；未知不命名为一种研究场景。

## 4. 选对象、分方法

按论文直接改变的数据、模型模块、状态、执行单元或请求分对象。每个对象用一句话说明什么成本或能力不足；名字应在读论文前也能理解。

在对象内按主要做法继续细分，必要时加信号、决策机制、作用粒度或阶段。训练要求、平台和数据集通常是独立属性；不同分支可不同深度。围绕已收录工作提出分类，避免先发明抽象树再强行装入。

每篇一条主统计路径；联合方法按核心贡献、主要实验和已约定的优先规则归一，其他贡献保留标签。一个父组的子组合计与父组一致；阅读集合可以交叉，但不混为唯一论文数。

人逐层选择分支。已有授权或已明确选择不反复确认，普通标签修正可带依据进行；改变范围/分类维度的决定需让人知情选择。

分类提案直接复用最终导航作预览：同一场景下看对象图，继续下钻方法和论文。用独立 taxonomy-proposal.json 记录待确认树与分配，保留原分类和人的决策；不因等待确认改做独立“分组提案”顶层页。评测/建模可在父组单列并解释子组合计差额。

### 只用存量和增长

- 存量：同一观察窗口、来源、筛选下的唯一论文数。未知属性只随“全部”计入。
- 增长：目标来源按发表/明确的录用年，预印本按首版公开年，分开画。年份精度足够年度图，不据此猜月份。
- 展示两期数与增量。小基数不用倍率排名，零基数倍率不定义；未完整年度标出，不计算全年增幅。
- 日期未知但有观察窗口归属证据的记录计入存量，年度图说明排除篇数；窗口归属也未知时先核实，不截日期或猜默认月份。
- 存量、增长不直接证明需求、竞争、机会或价值。补收新来源导致的增加不解释为学科增长。
- UI 的增长区保留分池年度卡；按 statistics.annual_trend 区分暂缓、描述性分布和可比较增幅，不以去掉视图区块掩盖覆盖条件。

组内问题具体、机制能直接比较时进入全文阅读；再拆主要剩超参或单篇论文时停止。候选初筛不要求先读几千篇全文。

## 5. 精读与交付

按 `reading-and-figures.md` 完成本组拆解、人核对关键原文。生成前按 `ui-contract.md` 检查参考页的四级结构与交互。交付可查来源的 HTML、项目 JSON 与状态记录，说明范围和实际阅读等级。本 skill 不继续生成 idea 或执行模型验证。

先运行 audit 与 validate，内部解决队列遗漏、证据失配、计数/日期错误和可复现的 UI 问题，再用 deliver 交付。没有完成记录的既有标签不自动获得本轮“完整摘要已读”状态；阶段性导出保留原因与下一批队列。人确认研究取舍，不承担替 AI 查常规脚本错误的职责。
